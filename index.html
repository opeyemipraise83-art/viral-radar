Get your free YouTube API key (5 min, no card)

  1. Go to console.cloud.google.com and sign in with any Google account.
  2. At the top, click the project dropdown → New Project → name it viral-radar → Create.
  3. In the search bar type YouTube Data API v3 → open it → click Enable.
  4. Left menu → APIs & Services → Credentials → + Create Credentials → API key.
  5. Copy the key it shows you. Paste it into the box up top and hit Save Keys. Done!

It's free — Google gives you 10,000 units/day (~100 searches). No partnership needed; this is the official, allowed way to read public YouTube data. Want more scans? Make a few Google Cloud projects (each gets its own free 10,000/day), create a key in each, and paste them one per line in the box. Viral Radar automatically jumps to the next key the moment one hits its daily limit — so you never have to swap keys by hand. After it works, "Restrict key" → limit to YouTube Data API v3 so it can't be misused.
