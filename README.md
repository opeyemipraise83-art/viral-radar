# Viral Radar

A browser-only YouTube research tool: finds faceless channels that are blowing up
right now across any niche. Opens straight into a live "Blowing up now" feed.

- 100% client-side — no server, no build step.
- Your YouTube Data API key(s) are stored only in your own browser (localStorage).
- Paste one key per line for automatic multi-key rotation.

## Deploy
Static site. On Vercel: Framework Preset = **Other**, no build command,
output = repo root. Just import and deploy.

## Local
Open `index.html` in any browser, or run `npx serve`.
